# ملف الإنجاز — ورقة العمل الإلكترونية

مشروع مستقل: نظام يربط المعلم بالطلاب عبر أوراق عمل تفاعلية مستخرجة تلقائيًا من ملفات PDF، مع ملف إنجاز تراكمي لكل طالب.

## الحالة الحالية: المرحلة 1 — الأساس التقني ✅

- هيكلة قاعدة بيانات Firestore كاملة (`shared/schema.md`)
- إعداد اتصال Firebase (`shared/firebase-config.js` — يحتاج ملء المفاتيح الفعلية)
- دوال توليد والتحقق من PIN الطالب (`shared/utils.js`)
- أنماط CSS مشتركة (`shared/styles.css`)
- هيكلة الصفحات المنفصلة (معلم × 5، طالب × 5) — حاليًا هياكل فارغة (placeholders)

## هيكلة المجلدات

```
/
├── index.html                  ← صفحة تنقل للتطوير فقط
├── shared/
│   ├── firebase-config.js
│   ├── schema.md
│   ├── styles.css
│   └── utils.js
├── teacher/
│   ├── students.html           ← إدارة الطلاب (رفع، PIN، نقل بين الفصول)
│   ├── upload-worksheets.html  ← رفع PDF وتحويله
│   ├── submissions.html        ← متابعة التسليمات
│   └── portfolio.html          ← ملف الإنجاز (عرض المعلم)
└── student/
    ├── login.html               ← دخول بالـ PIN
    ├── worksheets.html          ← قائمة الأوراق
    ├── solve.html               ← حل الورقة
    └── portfolio.html          ← ملف الإنجاز (عرض الطالب)
```

## المراحل القادمة

2. محرك استخراج التمارين من PDF + بناء أنواع التفاعل (فراغات، جداول، اختيار، صح/خطأ، مزاوجة، ترتيب)
3. بناء منطق صفحات المعلم الخمس
4. بناء منطق صفحات الطالب الخمس
5. ربط ملف الإنجاز التراكمي

## قبل النشر

- استبدال المفاتيح الوهمية في `shared/firebase-config.js` بمفاتيح مشروع Firebase الفعلي
- إنشاء مشروع Firebase جديد + تفعيل Firestore وStorage
